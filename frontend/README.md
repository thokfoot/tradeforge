# frontend

**Purpose:** The customer-facing app. Web + PWA (installable on mobile home screen AND Windows — ₹0 store fees). Native apps Phase 3.

## Stack
- React + Next.js + Tailwind
- TradingView **lightweight-charts** (open source, same engine family as TradingView) for world-class visuals
- PWA: responsive layout, offline shell, install prompt

## Key screens (Phase 1)
1. **Onboarding wizard** — beginner-guided, asks experience level, sets up demo account
2. **Dashboard** — portfolio, watchlists, market overview, AI assistant entry
3. **Charts** — candles, indicators, drawing tools, multi-timeframe
4. **Backtest** — strategy setup (no-code), run, results + metrics + equity curve
5. **Paper trading** — order ticket, positions, orders, history
6. **Screener** — filters, results
7. **AI Assistant** — chat + voice, teacher/listener/doer, any language
8. **Journal** (Phase 2), **Settings** (export data / my-git, subscription)

## Rules
- Mobile-first but desktop-polished (Windows app feel).
- Hindi/Hinglish language toggle (Phase 2 full; onboarding bilingual from start).
- Every results screen carries risk disclaimer.

**Status:** Planning. Scaffold starts with Phase 1.
