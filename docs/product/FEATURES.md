# Features — by user level & plan

## Free tier (beginner acquisition)
- Charts: candlesticks, multiple timeframes, ~50 indicators, drawing tools (lightweight-charts)
- Watchlists, basic technical + fundamental screener
- Paper trading with virtual balance (limited backtests/day, limited strategies)
- Education: basic lessons + AI teacher (limited)
- One market allowed by default; upgrade to unlock others

## Pro tier (₹99–199/mo target) — "the 4-tools bundle"
- All markets: India (NSE/BSE all + indices) + US + Crypto
- Unlimited backtests, realistic cost model + slippage
- Paper trading: full order types (market/limit/SL/bracket), resettable balance
- No-code strategy builder + strategy versioning
- Trading journal, alerts, data export (CSV + "export to my git")
- AI assistant full: teacher + listener + doer (text + voice, any language)
- Advanced metrics: win rate, profit factor, max DD, expectancy, R-multiple, equity curve

## Expert tier (₹299–499/mo, Phase 3)
- Options/F&O backtesting
- Intraday (India included)
- Parameter optimization, walk-forward, Monte Carlo
- API access, code mode (Python) in sandbox
- Priority compute, advanced analytics/reports
